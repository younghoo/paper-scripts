This repository contains the scripts for the paper: 

Jiaqi Gao, Yang Hu; MIND versus MSN: a systematic evaluation of test-retest reliability and age sensitivity for T1-weighted structural similarity networks. Network Neuroscience 2026; doi: https://doi.org/10.1162/NETN.a.553

The scripts are organized into four folders corresponding to the key stages of the study: `PREPROC` for preprocessing and quality control, `MIND` and `MSN` for network construction, and `TRT` and `AGE` for evaluating test-retest reliability and age sensitivity, respectively.
